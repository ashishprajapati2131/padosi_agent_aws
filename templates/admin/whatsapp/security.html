Zero-Vulnerability Standards
🔐 Credential Leakage Shield

Password plaintext is completely removed from all payment callbacks and confirmation web views. Only the agent's verified WhatsApp and private email receive credentials.

🛡️ Anti-Spoofing Webhooks

Payment callbacks explicitly cross-verify captured status with Razorpay API. An attacker cannot synthesize a fake URL to activate membership for free.

⚡ Anti-Spam Rate Limiting

Incoming messages are throttled to a maximum of 10 requests per minute per phone number via Django memory cache.
